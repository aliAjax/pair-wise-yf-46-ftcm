# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 多岗协作与断网合并模型

旧实现把整份串联单写进同一个 localStorage key，两个岗位（主控/现场）同时编辑时最后写入直接覆盖。现在改为：

- **带版本号的“服务端”文档**（`src/sync/server.ts`，用 localStorage 模拟；乐观锁 `revision`，过期推送返回 409）。
- **本机草稿**（`src/sync/draft.ts`）：断网后所有编排独立落盘，刷新/关机不丢，且永远不会覆盖服务端文档。
- **三路字段合并**（`src/sync/merge.ts`，base 共同基线 / local 现场草稿 / remote 主控最新）：
  - 只一边改的字段（现场调时长、主控安排硬时间/挪广告位）自动合入；
  - 同一条目的同一字段两边不同 → 各留一版进入「合并确认」，人工选择后再提交；
  - 一边删条目、另一边改字段 → 删除冲突，二选一；
  - 两边都重排且顺序不一致 → 顺序冲突。
- **顺序变更即时重算**（`src/logic/timeline.ts`）：每条按时长累加推算开播时间，与硬时间比对并量化迟到分钟数；硬时间风险在任何增删/拖拽/时长变化后立即刷新。
- **突发插播锚点迁移**：插播条目带 `anchorId`，锚点被移动/重排时插播自动跟到锚点之后；锚点被删除则顺延到锚点前最近的存活条目；推送期间编辑锁定，避免在途推送覆盖新改动。
- **失败保护**：推送或合并因网络失败时，状态进入 error，本地草稿原样保留，横幅与应急队列页提供「保留草稿并重试」。
- **岗位权限**（`src/logic/permissions.ts`）：字幕岗只有文案字段与播出状态权限，拖拽排序、时长加减、硬时间、删除、插播、撤回均被 reducer 与 UI 双重拒绝。

## 演示流程（单浏览器开两个标签页模拟主控/现场）

1. 标签页 A（现场）：把顶部「链路在线」关掉 → 增删条目、改时长、发突发插播；
2. 点横幅上的「模拟主控此时调广告位/硬时间」（等同于标签页 B 的主控操作，直接在服务端写新版本）；
3. 重新打开链路 → 自动三路合并；无冲突静默合入，有同字段双版本则进入「合并确认」页逐处选择；
4. 断网状态下点重试按钮（或直接断网推送）可看到 error 态：草稿保留、可重试。
